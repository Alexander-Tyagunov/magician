Common AI mistakes: SQL injection via string concatenation; XSS via innerHTML with user content; SSRF by fetching user-provided URLs without validation; storing passwords in plaintext.
Checklist: parameterize all queries; escape all output; validate/allowlist URLs; hash passwords with bcrypt/argon2; set Content-Security-Policy; use HTTPS only.
Gotchas: auth !== authz; JWTs are not encrypted by default; CORS misconfiguration allows cross-origin reads; rate-limit all auth endpoints.
Model fallback: cyber/bio classifiers can silently move a session to an older model (Fable 5.1 / Opus 5.5 → Opus 5 on bio, Opus 4.8 on cyber; Sonnet 5.5 → Sonnet 5 on cyber) and it stays there. Security skills print the active model at start and end so a mid-run switch is visible; to be asked instead set `switchModelsOnFlag: false`, to refuse the switch set `CLAUDE_CODE_DISABLE_REFUSAL_FALLBACK=1`; cloud providers need `ANTHROPIC_DEFAULT_*_MODEL` pins for the fallback targets. Details: lore/models.md.
